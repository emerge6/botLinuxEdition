Команда: ls
Описание: Выводит список файлов и директорий в текущей директории. Поддерживает множество опций для настройки вывода. Опции: -l (подробный список с правами, владельцем, размером), -a (включая скрытые файлы, начинающиеся с точки), -h (человеко-читаемый формат размеров), -R (рекурсивный вывод). Пример: ls -lah /home/user.
Источник: https://man7.org/linux/man-pages/man1/ls.1.html

Команда: dir
Описание: Аналог ls, выводит содержимое директории, но с другим форматом по умолчанию (вертикальный список). Используется реже, но полезен в скриптах. Опции: -l (длинный формат), -a (все файлы). Пример: dir -l /etc.
Источник: https://man7.org/linux/man-pages/man1/dir.1.html

Команда: cd
Описание: Меняет текущую директорию. Без аргументов возвращает в домашнюю директорию пользователя (~). Поддерживает относительные и абсолютные пути, а также специальные символы, такие как .. (родительская директория) или - (предыдущая директория). Пример: cd /usr/local/bin.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Directory-Stack-Builtins

Команда: pwd
Описание: Выводит полный абсолютный путь к текущей рабочей директории. Полезно для ориентации в файловой системе или в скриптах. Опция -P показывает физический путь, исключая символические ссылки. Пример: pwd -P.
Источник: https://man7.org/linux/man-pages/man1/pwd.1.html

Команда: chmod
Описание: Изменяет права доступа к файлам или директориям. Права задаются в числовом (например, 755) или символьном формате (например, u+x). Числовой формат: первая цифра — владелец, вторая — группа, третья — остальные; 4=чтение, 2=запись, 1=выполнение. Опции: -R (рекурсивно). Пример: chmod -R 644 /var/www.
Источник: https://man7.org/linux/man-pages/man1/chmod.1.html

Команда: chown
Описание: Изменяет владельца и/или группу файлов или директорий. Поддерживает числовые ID (UID/GID) или имена пользователей/групп. Опция -R для рекурсивного применения. Пример: chown -R user:group /home/user.
Источник: https://man7.org/linux/man-pages/man1/chown.1.html

Команда: grep
Описание: Ищет строки, соответствующие регулярному выражению, в файлах или стандартном вводе. Поддерживает мощные шаблоны поиска. Опции: -i (игнорировать регистр), -r (рекурсивный поиск в директориях), -v (инвертировать совпадения), -n (показать номера строк). Пример: grep -rin "error" /var/log.
Источник: https://man7.org/linux/man-pages/man1/grep.1.html

Команда: egrep
Описание: Расширенная версия grep, поддерживающая расширенные регулярные выражения (ERE) по умолчанию. Эквивалент grep -E. Полезна для сложных шаблонов. Пример: egrep "(error|warning)" log.txt.
Источник: https://man7.org/linux/man-pages/man1/grep.1.html

Команда: fgrep
Описание: Быстрая версия grep, интерпретирующая шаблон как фиксированную строку, а не регулярное выражение. Эквивалент grep -F. Полезна для поиска литералов. Пример: fgrep "literal string" file.txt.
Источник: https://man7.org/linux/man-pages/man1/grep.1.html

Команда: cat
Описание: Выводит содержимое одного или нескольких файлов в стандартный вывод. Может объединять файлы или перенаправлять вывод. Опции: -n (нумерация строк), -b (нумерация только непустых строк). Пример: cat file1.txt file2.txt > combined.txt.
Источник: https://man7.org/linux/man-pages/man1/cat.1.html

Команда: tac
Описание: Выводит содержимое файла в обратном порядке (последняя строка становится первой). Полезно для логов или обратного просмотра данных. Пример: tac log.txt.
Источник: https://man7.org/linux/man-pages/man1/tac.1.html

Команда: rm
Описание: Удаляет файлы или директории. Опасная команда, так как удаление необратимо. Опции: -r (рекурсивно, для директорий), -f (без подтверждения), -i (запрашивать подтверждение). Пример: rm -rf /tmp/old_data.
Источник: https://man7.org/linux/man-pages/man1/rm.1.html

Команда: rmdir
Описание: Удаляет пустые директории. Более безопасна, чем rm -r, так как не удаляет непустые директории. Опция -p удаляет родительские директории, если они пусты. Пример: rmdir /tmp/empty_dir.
Источник: https://man7.org/linux/man-pages/man1/rmdir.1.html

Команда: mkdir
Описание: Создаёт новую директорию. Опция -p позволяет создавать вложенные директории, не выдавая ошибку, если они уже существуют. Пример: mkdir -p /home/user/projects/new.
Источник: https://man7.org/linux/man-pages/man1/mkdir.1.html

Команда: cp
Описание: Копирует файлы или директории. Поддерживает копирование структуры директорий. Опции: -r (рекурсивно), -p (сохранять атрибуты, такие как права и время), -u (копировать только обновленные файлы). Пример: cp -r /src /dst.
Источник: https://man7.org/linux/man-pages/man1/cp.1.html

Команда: mv
Описание: Перемещает или переименовывает файлы и директории. Не копирует данные, а изменяет их местоположение. Опции: -i (запрашивать подтверждение при перезаписи), -u (перемещать только если источник новее). Пример: mv oldname.txt newname.txt.
Источник: https://man7.org/linux/man-pages/man1/mv.1.html

Команда: touch
Описание: Создаёт пустой файл или обновляет время модификации существующего файла. Полезно для создания заглушек или тестирования. Опции: -t (задать конкретное время), -a (изменить только время доступа). Пример: touch newfile.txt.
Источник: https://man7.org/linux/man-pages/man1/touch.1.html

Команда: ln
Описание: Создаёт жесткие или символические ссылки на файлы. Жесткая ссылка указывает на те же данные, символическая — на путь. Опция -s для создания символьных ссылок. Пример: ln -s /target/file /link/to/file.
Источник: https://man7.org/linux/man-pages/man1/ln.1.html

Команда: find
Описание: Ищет файлы и директории в файловой системе по заданным критериям (имя, размер, тип, время модификации и т.д.). Очень мощная утилита. Опции: -name (поиск по имени), -type (тип файла, например, f для файлов, d для директорий), -exec (выполнить команду над найденным). Пример: find / -type f -name "*.txt".
Источник: https://man7.org/linux/man-pages/man1/find.1.html

Команда: locate
Описание: Быстро ищет файлы по имени в базе данных, созданной утилитой updatedb. Быстрее, чем find, но зависит от актуальности базы. Пример: locate myfile.txt.
Источник: https://man7.org/linux/man-pages/man1/locate.1.html

Команда: updatedb
Описание: Обновляет базу данных для утилиты locate. Обычно выполняется автоматически через cron, но может быть запущена вручную. Опция --localpaths задаёт директории для индексации. Пример: updatedb.
Источник: https://man7.org/linux/man-pages/man8/updatedb.8.html

Команда: du
Описание: Оценивает размер файлов и директорий. Показывает, сколько места занимает каждая директория или файл. Опции: -h (человеко-читаемый формат, например, MB/GB), -s (суммарный размер), --max-depth (ограничить глубину вложенности). Пример: du -sh /home/user.
Источник: https://man7.org/linux/man-pages/man1/du.1.html

Команда: df
Описание: Показывает информацию о свободном и занятом месте на дисках и файловых системах. Опции: -h (человеко-читаемый формат), -T (показать тип файловой системы). Пример: df -h.
Источник: https://man7.org/linux/man-pages/man1/df.1.html

Команда: echo
Описание: Выводит текст в стандартный вывод или в файл. Часто используется в скриптах для вывода переменных или сообщений. Опции: -n (не добавлять новую строку), -e (интерпретировать escape-последовательности). Пример: echo "Hello, $USER" > greeting.txt.
Источник: https://man7.org/linux/man-pages/man1/echo.1.html

Команда: printf
Описание: Форматированный вывод текста, более мощный, чем echo. Поддерживает форматирование чисел, строк и т.д. Пример: printf "User: %s, ID: %d\n" "$USER" "$(id -u)".
Источник: https://man7.org/linux/man-pages/man1/printf.1.html

Команда: whoami
Описание: Выводит имя текущего пользователя, от лица которого выполняется команда. Полезно в скриптах или для проверки привилегий. Пример: whoami.
Источник: https://man7.org/linux/man-pages/man1/whoami.1.html

Команда: id
Описание: Выводит информацию о текущем пользователе или указанном пользователе: UID, GID и группы. Опции: -u (только UID), -g (только GID), -n (имя вместо числа). Пример: id -un.
Источник: https://man7.org/linux/man-pages/man1/id.1.html

Команда: uname
Описание: Выводит информацию о системе: имя ядра, версию, архитектуру и т.д. Опция -a показывает всю доступную информацию. Пример: uname -a.
Источник: https://man7.org/linux/man-pages/man1/uname.1.html

Команда: ps
Описание: Показывает список запущенных процессов. Может отображать процессы текущего пользователя или всей системы. Опции: -aux (подробный список всех процессов), -ef (альтернативный формат). Пример: ps aux | grep python.
Источник: https://man7.org/linux/man-pages/man1/ps.1.html

Команда: kill
Описание: Завершает процесс по его идентификатору (PID). Поддерживает отправку различных сигналов (например, SIGTERM, SIGKILL). Опции: -s (указать сигнал), -l (список сигналов). Пример: kill -9 1234.
Источник: https://man7.org/linux/man-pages/man1/kill.1.html

Команда: killall
Описание: Завершает процессы по их имени, а не PID. Удобно для остановки всех экземпляров программы. Опции: -i (запрашивать подтверждение), -u (по пользователю). Пример: killall firefox.
Источник: https://man7.org/linux/man-pages/man1/killall.1.html

Команда: pkill
Описание: Завершает процессы по имени или другим критериям (например, пользователю). Более гибкая, чем killall. Опции: -u (по пользователю), -f (поиск по полной командной строке). Пример: pkill -u user.
Источник: https://man7.org/linux/man-pages/man1/pkill.1.html

Команда: top
Описание: Интерактивный монитор процессов в реальном времени. Показывает загрузку CPU, память, PID, пользователя и т.д. Поддерживает сортировку и фильтрацию. Пример: top.
Источник: https://man7.org/linux/man-pages/man1/top.1.html

Команда: htop
Описание: Улучшенная версия top с цветным интерфейсом, поддержкой мыши и удобным управлением (например, завершение процессов). Требует установки. Пример: htop.
Источник: https://man7.org/linux/man-pages/man1/htop.1.html

Команда: glances
Описание: Мощный системный монитор, показывающий процессы, сеть, диски, CPU, память и многое другое в одном интерфейсе. Поддерживает клиент-серверный режим. Пример: glances.
Источник: https://nicolargo.github.io/glances/

Команда: ping
Описание: Проверяет доступность хоста в сети, отправляя ICMP-пакеты. Показывает время отклика. Опции: -c (количество пакетов), -i (интервал). Пример: ping -c 4 google.com.
Источник: https://man7.org/linux/man-pages/man8/ping.8.html

Команда: traceroute
Описание: Отображает маршрут пакетов до указанного хоста, показывая промежуточные узлы. Полезно для диагностики сети. Опции: -n (без разрешения имен), -m (максимальное количество прыжков). Пример: traceroute google.com.
Источник: https://man7.org/linux/man-pages/man8/traceroute.8.html

Команда: wget
Описание: Скачивает файлы из интернета по HTTP, HTTPS или FTP. Поддерживает рекурсивную загрузку и докачку. Опции: -c (возобновить загрузку), -r (рекурсивно). Пример: wget -c https://example.com/file.zip.
Источник: https://man7.org/linux/man-pages/man1/wget.1.html

Команда: curl
Описание: Многофункциональный инструмент для передачи данных по различным протоколам (HTTP, FTP, SMTP и др.). Используется для скачивания, API-запросов и тестирования. Опции: -O (сохранить с оригинальным именем), -X (метод запроса). Пример: curl -O https://example.com/file.txt.
Источник: https://man7.org/linux/man-pages/man1/curl.1.html

Команда: tar
Описание: Создаёт, распаковывает или управляет архивами. Поддерживает сжатие (gzip, bzip2, xz). Опции: -c (создать), -x (извлечь), -f (файл архива), -z (gzip), -j (bzip2). Пример: tar -czvf archive.tar.gz /dir.
Источник: https://man7.org/linux/man-pages/man1/tar.1.html

Команда: gzip
Описание: Сжимает файлы, заменяя их на .gz версию. Не архивирует, только сжимает один файл. Опции: -d (распаковать), -k (сохранить оригинал). Пример: gzip file.txt.
Источник: https://man7.org/linux/man-pages/man1/gzip.1.html

Команда: gunzip
Описание: Распаковывает .gz файлы, восстанавливая оригинал. Эквивалент gzip -d. Пример: gunzip file.txt.gz.
Источник: https://man7.org/linux/man-pages/man1/gunzip.1.html

Команда: bzip2
Описание: Сжимает файлы с использованием алгоритма bzip2, обеспечивая лучшее сжатие, чем gzip, но медленнее. Опции: -d (распаковать), -k (сохранить оригинал). Пример: bzip2 file.txt.
Источник: https://man7.org/linux/man-pages/man1/bzip2.1.html

Команда: xz
Описание: Сжимает файлы с использованием алгоритма LZMA, обеспечивая высокую степень сжатия. Опции: -d (распаковать), -k (сохранить оригинал). Пример: xz file.txt.
Источник: https://man7.org/linux/man-pages/man1/xz.1.html

Команда: zip
Описание: Создаёт архивы в формате .zip, совместимые с Windows и другими системами. Поддерживает сжатие нескольких файлов. Опции: -r (рекурсивно), -q (тихо). Пример: zip -r archive.zip /dir.
Источник: https://man7.org/linux/man-pages/man1/zip.1.html

Команда: unzip
Описание: Распаковывает .zip архивы. Опции: -l (список содержимого), -d (директория для распаковки). Пример: unzip archive.zip -d /tmp.
Источник: https://man7.org/linux/man-pages/man1/unzip.1.html

Команда: sed
Описание: Потоковый текстовый редактор для обработки текста. Используется для замены, удаления или вставки строк. Опции: -i (редактировать файл на месте), -e (выполнить команду). Пример: sed 's/old/new/g' file.txt.
Источник: https://man7.org/linux/man-pages/man1/sed.1.html

Команда: awk
Описание: Мощный инструмент для обработки и анализа текстовых данных, особенно структурированных (например, CSV). Поддерживает программирование на собственном языке. Пример: awk '{print $1}' file.txt.
Источник: https://man7.org/linux/man-pages/man1/awk.1.html

Команда: cut
Описание: Извлекает части строк из файлов или ввода, разделяя их по разделителю. Опции: -d (задать разделитель), -f (выбрать поля). Пример: cut -d':' -f1 /etc/passwd.
Источник: https://man7.org/linux/man-pages/man1/cut.1.html

Команда: sort
Описание: Сортирует строки в файле или вводе. Поддерживает числовую, лексикографическую и другие сортировки. Опции: -n (числовая), -r (обратная), -k (по ключу). Пример: sort -n numbers.txt.
Источник: https://man7.org/linux/man-pages/man1/sort.1.html

Команда: uniq
Описание: Удаляет или подсчитывает повторяющиеся строки в отсортированном вводе. Опции: -c (подсчитать вхождения), -d (только дубликаты). Пример: sort file.txt | uniq -c.
Источник: https://man7.org/linux/man-pages/man1/uniq.1.html

Команда: wc
Описание: Подсчитывает строки, слова и символы в файле или вводе. Опции: -l (строки), -w (слова), -c (байт). Пример: wc -l file.txt.
Источник: https://man7.org/linux/man-pages/man1/wc.1.html

Команда: head
Описание: Выводит первые строки файла или ввода. По умолчанию — 10 строк. Опция -n задаёт количество. Пример: head -n 5 file.txt.
Источник: https://man7.org/linux/man-pages/man1/head.1.html

Команда: tail
Описание: Выводит последние строки файла или ввода. По умолчанию — 10 строк. Опции: -n (количество строк), -f (следить за изменениями). Пример: tail -f /var/log/syslog.
Источник: https://man7.org/linux/man-pages/man1/tail.1.html

Команда: less
Описание: Позволяет просматривать файлы постранично с возможностью прокрутки назад и поиска. Более удобен, чем more. Пример: less /var/log/syslog.
Источник: https://man7.org/linux/man-pages/man1/less.1.html

Команда: more
Описание: Простой пейджер для просмотра файлов с прокруткой только вперёд. Менее функционален, чем less. Пример: more file.txt.
Источник: https://man7.org/linux/man-pages/man1/more.1.html

Команда: nano
Описание: Простой текстовый редактор для терминала. Поддерживает подсветку синтаксиса и базовые функции редактирования. Пример: nano file.txt.
Источник: https://www.nano-editor.org/dist/latest/nano.html

Команда: vim
Описание: Мощный текстовый редактор с режимами (командный, вставка) и поддержкой плагинов. Имеет крутую кривую обучения. Пример: vim file.txt.
Источник: https://www.vim.org/docs.php

Команда: emacs
Описание: Расширяемый текстовый редактор и экосистема для программирования, работы с текстом и многого другого. Пример: emacs file.txt.
Источник: https://www.gnu.org/software/emacs/manual/emacs.html

Команда: man
Описание: Отображает справочные страницы для команд и утилит. Основной источник документации в Linux. Опции: -k (поиск по ключевому слову). Пример: man ls.
Источник: https://man7.org/linux/man-pages/man1/man.1.html

Команда: info
Описание: Показывает документацию в формате GNU info, часто более подробную, чем man. Пример: info coreutils.
Источник: https://www.gnu.org/software/texinfo/manual/info/

Команда: apropos
Описание: Ищет команды по ключевому слову в их описаниях в man-страницах. Полезно для поиска подходящей утилиты. Пример: apropos copy.
Источник: https://man7.org/linux/man-pages/man1/apropos.1.html

Команда: whatis
Описание: Выводит краткое описание команды из базы данных man. Пример: whatis ls.
Источник: https://man7.org/linux/man-pages/man1/whatis.1.html

Команда: which
Описание: Показывает полный путь к исполняемому файлу команды в PATH. Полезно для определения, какая версия команды используется. Пример: which python3.
Источник: https://man7.org/linux/man-pages/man1/which.1.html

Команда: whereis
Описание: Ищет исполняемые файлы, исходные коды и man-страницы для команды. Более широкий поиск, чем which. Пример: whereis gcc.
Источник: https://man7.org/linux/man-pages/man1/whereis.1.html

Команда: file
Описание: Определяет тип файла (текст, бинарный, архив и т.д.) на основе его содержимого. Опции: -i (MIME-тип), -b (краткий вывод). Пример: file document.pdf.
Источник: https://man7.org/linux/man-pages/man1/file.1.html

Команда: stat
Описание: Показывает подробную информацию о файле или файловой системе: права, время модификации, размер, иноды и т.д. Пример: stat file.txt.
Источник: https://man7.org/linux/man-pages/man1/stat.1.html

Команда: diff
Описание: Сравнивает два файла или директории и показывает различия построчно. Опции: -u (унифицированный формат), -r (рекурсивно). Пример: diff file1.txt file2.txt.
Источник: https://man7.org/linux/man-pages/man1/diff.1.html

Команда: cmp
Описание: Сравнивает два файла побайтно и сообщает о первом различии. Полезно для бинарных файлов. Пример: cmp file1.bin file2.bin.
Источник: https://man7.org/linux/man-pages/man1/cmp.1.html

Команда: patch
Описание: Применяет изменения (патчи), созданные diff, к файлу. Используется для обновления исходного кода. Пример: patch file.txt < patchfile.
Источник: https://man7.org/linux/man-pages/man1/patch.1.html

Команда: tee
Описание: Читает стандартный ввод и записывает его одновременно в стандартный вывод и файлы. Полезно для логирования. Опция -a добавляет, а не перезаписывает. Пример: ls | tee output.txt.
Источник: https://man7.org/linux/man-pages/man1/tee.1.html

Команда: xargs
Описание: Преобразует стандартный ввод в аргументы для другой команды. Часто используется с find. Опции: -n (число аргументов за раз), -I (замена строки). Пример: find . -name "*.txt" | xargs rm.
Источник: https://man7.org/linux/man-pages/man1/xargs.1.html

Команда: bc
Описание: Интерактивный калькулятор для точных вычислений, включая дробные числа и функции. Поддерживает скрипты. Пример: echo "5 * 3.14" | bc.
Источник: https://man7.org/linux/man-pages/man1/bc.1.html

Команда: expr
Описание: Выполняет простые арифметические и строковые операции. Устаревшая, но всё ещё используется в скриптах. Пример: expr 5 + 3.
Источник: https://man7.org/linux/man-pages/man1/expr.1.html

Команда: test
Описание: Проверяет условия (например, существование файла, равенство строк) в скриптах. Обычно используется в [ ] или [[ ]]. Пример: test -f file.txt.
Источник: https://man7.org/linux/man-pages/man1/test.1.html

Команда: true
Описание: Возвращает успешный код возврата (0). Используется в скриптах как заглушка или для циклов. Пример: while true; do echo "Running"; done.
Источник: https://man7.org/linux/man-pages/man1/true.1.html

Команда: false
Описание: Возвращает неуспешный код возврата (1). Используется в скриптах для тестирования или выхода. Пример: false && echo "Never printed".
Источник: https://man7.org/linux/man-pages/man1/false.1.html

Команда: sleep
Описание: Приостанавливает выполнение на заданное время (в секундах, минутах и т.д.). Полезно в скриптах. Пример: sleep 5s.
Источник: https://man7.org/linux/man-pages/man1/sleep.1.html

Команда: time
Описание: Измеряет время выполнения команды и её использование ресурсов (CPU, память). Пример: time ls.
Источник: https://man7.org/linux/man-pages/man1/time.1.html

Команда: date
Описание: Выводит или устанавливает системное время и дату. Поддерживает форматирование вывода. Опции: -s (установить), +% (формат). Пример: date +%Y-%m-%d.
Источник: https://man7.org/linux/man-pages/man1/date.1.html

Команда: cal
Описание: Выводит календарь на текущий месяц или заданный год. Опции: -y (весь год), -3 (три месяца). Пример: cal 2023.
Источник: https://man7.org/linux/man-pages/man1/cal.1.html

Команда: uptime
Описание: Показывает, как долго система работает, текущую загрузку и количество пользователей. Пример: uptime.
Источник: https://man7.org/linux/man-pages/man1/uptime.1.html

Команда: w
Описание: Показывает, кто вошёл в систему, и что они делают (запущенные процессы). Пример: w.
Источник: https://man7.org/linux/man-pages/man1/w.1.html

Команда: who
Описание: Показывает список пользователей, вошедших в систему, с их терминалами и временем входа. Пример: who.
Источник: https://man7.org/linux/man-pages/man1/who.1.html

Команда: last
Описание: Показывает историю входов и выходов пользователей в систему на основе логов. Опции: -n (число записей). Пример: last -n 10.
Источник: https://man7.org/linux/man-pages/man1/last.1.html

Команда: free
Описание: Показывает информацию о свободной и занятой оперативной памяти и swap. Опции: -h (человеко-читаемый формат), -s (обновление в реальном времени). Пример: free -h.
Источник: https://man7.org/linux/man-pages/man1/free.1.html

Команда: vmstat
Описание: Показывает статистику использования памяти, CPU, дисков и процессов. Опции: -s (подробная сводка), -d (диски). Пример: vmstat 1.
Источник: https://man7.org/linux/man-pages/man8/vmstat.8.html

Команда: iostat
Описание: Показывает статистику ввода-вывода для дисков и CPU. Полезно для анализа производительности. Пример: iostat -x.
Источник: https://man7.org/linux/man-pages/man1/iostat.1.html

Команда: dmesg
Описание: Выводит сообщения ядра Linux (логи загрузки, ошибки оборудования и т.д.). Опции: -T (человеко-читаемые метки времени), --level (фильтр по уровню). Пример: dmesg | grep error.
Источник: https://man7.org/linux/man-pages/man8/dmesg.8.html

Команда: journalctl
Описание: Просматривает и управляет системными логами, собранными systemd. Опции: -u (по юниту), -b (с последней загрузки), -f (следить). Пример: journalctl -u sshd.
Источник: https://man7.org/linux/man-pages/man1/journalctl.1.html

Команда: systemctl
Описание: Управляет сервисами и юнитами в systemd: запуск, остановка, перезапуск, статус. Опции: start, stop, restart, status. Пример: systemctl restart nginx.
Источник: https://man7.org/linux/man-pages/man1/systemctl.1.html

Команда: service
Описание: Упрощённый интерфейс для управления сервисами (включая systemd и SysVinit). Пример: service apache2 restart.
Источник: https://man7.org/linux/man-pages/man8/service.8.html

Команда: init
Описание: Управляет уровнями выполнения системы (SysVinit). В современных системах заменён systemd. Пример: init 3.
Источник: https://man7.org/linux/man-pages/man8/init.8.html

Команда: reboot
Описание: Перезагружает систему. Может быть использована с опцией --force для немедленной перезагрузки. Пример: reboot.
Источник: https://man7.org/linux/man-pages/man8/reboot.8.html

Команда: shutdown
Описание: Выключает или перезагружает систему с возможностью указания времени. Опции: -r (перезагрузка), -h (выключение). Пример: shutdown -h now.
Источник: https://man7.org/linux/man-pages/man8/shutdown.8.html

Команда: halt
Описание: Немедленно останавливает систему (без корректного завершения процессов). Используется редко. Пример: halt.
Источник: https://man7.org/linux/man-pages/man8/halt.8.html

Команда: poweroff
Описание: Выключает систему, корректно завершая процессы. Аналог shutdown -h. Пример: poweroff.
Источник: https://man7.org/linux/man-pages/man8/poweroff.8.html

Команда: mount
Описание: Подключает файловую систему к указанной точке монтирования. Требует прав root для большинства операций. Пример: mount /dev/sdb1 /mnt.
Источник: https://man7.org/linux/man-pages/man8/mount.8.html

Команда: umount
Описание: Отключает файловую систему от точки монтирования. Пример: umount /mnt.
Источник: https://man7.org/linux/man-pages/man8/umount.8.html

Команда: fdisk
Описание: Инструмент для работы с разделами диска: создание, удаление, изменение. Требует осторожности. Пример: fdisk /dev/sda.
Источник: https://man7.org/linux/man-pages/man8/fdisk.8.html

Команда: parted
Описание: Более современный инструмент для управления разделами, поддерживающий GPT и большие диски. Пример: parted /dev/sda.
Источник: https://www.gnu.org/software/parted/manual/parted.html

Команда: mkfs
Описание: Создаёт файловую систему на разделе (например, ext4, ntfs). Опции зависят от типа файловой системы. Пример: mkfs.ext4 /dev/sdb1.
Источник: https://man7.org/linux/man-pages/man8/mkfs.8.html

Команда: fsck
Описание: Проверяет и исправляет ошибки на файловой системе. Используется перед монтированием. Пример: fsck /dev/sdb1.
Источник: https://man7.org/linux/man-pages/man8/fsck.8.html

Команда: dd
Описание: Копирует данные побайтно, часто используется для создания образов дисков или копирования разделов. Опции: bs (размер блока), count (число блоков). Пример: dd if=/dev/sda of=/backup.img bs=4M.
Источник: https://man7.org/linux/man-pages/man1/dd.1.html

Команда: sync
Описание: Сбрасывает буферы файловой системы на диск, обеспечивая запись всех изменений. Пример: sync.
Источник: https://man7.org/linux/man-pages/man1/sync.1.html

Команда: chroot
Описание: Меняет корневую директорию для текущего процесса, изолируя его от остальной системы. Используется для тестирования или восстановления. Пример: chroot /mnt/newroot.
Источник: https://man7.org/linux/man-pages/man8/chroot.8.html

Команда: su
Описание: Переключает пользователя или запускает оболочку от имени другого пользователя. Без аргументов переключается на root. Пример: su - user.
Источник: https://man7.org/linux/man-pages/man1/su.1.html

Команда: sudo
Описание: Выполняет команду от имени другого пользователя, обычно root, с проверкой прав. Опции: -u (указать пользователя), -i (интерактивная оболочка). Пример: sudo apt update.
Источник: https://man7.org/linux/man-pages/man8/sudo.8.html

Команда: passwd
Описание: Изменяет пароль пользователя. Без аргументов меняет пароль текущего пользователя. Пример: passwd user.
Источник: https://man7.org/linux/man-pages/man1/passwd.1.html

Команда: useradd
Описание: Создаёт нового пользователя. Опции: -m (создать домашнюю директорию), -s (указать оболочку). Пример: useradd -m -s /bin/bash newuser.
Источник: https://man7.org/linux/man-pages/man8/useradd.8.html

Команда: usermod
Описание: Изменяет параметры существующего пользователя (группы, оболочку, домашнюю директорию). Пример: usermod -aG sudo user.
Источник: https://man7.org/linux/man-pages/man8/usermod.8.html

Команда: userdel
Описание: Удаляет пользователя. Опция -r удаляет также домашнюю директорию. Пример: userdel -r user.
Источник: https://man7.org/linux/man-pages/man8/userdel.8.html

Команда: groupadd
Описание: Создаёт новую группу. Опция -g задаёт GID. Пример: groupadd -g 1001 mygroup.
Источник: https://man7.org/linux/man-pages/man8/groupadd.8.html

Команда: groupmod
Описание: Изменяет параметры группы (имя, GID). Пример: groupmod -n newname oldname.
Источник: https://man7.org/linux/man-pages/man8/groupmod.8.html

Команда: groupdel
Описание: Удаляет группу. Невозможно, если группа является основной для пользователя. Пример: groupdel mygroup.
Источник: https://man7.org/linux/man-pages/man8/groupdel.8.html

Команда: chgrp
Описание: Изменяет группу-владельца файла или директории. Опция -R для рекурсивного применения. Пример: chgrp -R users /shared.
Источник: https://man7.org/linux/man-pages/man1/chgrp.1.html

Команда: getent
Описание: Извлекает записи из системных баз данных (пользователи, группы, хосты и т.д.). Пример: getent passwd user.
Источник: https://man7.org/linux/man-pages/man1/getent.1.html

Команда: hostname
Описание: Показывает или устанавливает имя хоста системы. Пример: hostname newhost.
Источник: https://man7.org/linux/man-pages/man1/hostname.1.html

Команда: hostnamectl
Описание: Управляет именем хоста в системах с systemd. Пример: hostnamectl set-hostname newhost.
Источник: https://man7.org/linux/man-pages/man1/hostnamectl.1.html

Команда: ifconfig
Описание: Настраивает и отображает информацию о сетевых интерфейсах. Устаревшая, заменяется ip. Пример: ifconfig eth0.
Источник: https://man7.org/linux/man-pages/man8/ifconfig.8.html

Команда: ip
Описание: Современный инструмент для управления сетевыми интерфейсами, маршрутами, туннелями и т.д. Пример: ip addr show.
Источник: https://man7.org/linux/man-pages/man8/ip.8.html

Команда: netstat
Описание: Показывает сетевые соединения, таблицы маршрутизации, статистику интерфейсов. Опции: -tulpn (прослушиваемые порты). Пример: netstat -tulpn.
Источник: https://man7.org/linux/man-pages/man8/netstat.8.html

Команда: ss
Описание: Современная замена netstat, показывает информацию о сокетах и соединениях. Пример: ss -tulpn.
Источник: https://man7.org/linux/man-pages/man8/ss.8.html

Команда: route
Описание: Управляет таблицей маршрутизации. Устаревшая, заменяется ip route. Пример: route -n.
Источник: https://man7.org/linux/man-pages/man8/route.8.html

Команда: arp
Описание: Управляет ARP-таблицей (сопоставление IP и MAC-адресов). Пример: arp -n.
Источник: https://man7.org/linux/man-pages/man8/arp.8.html

Команда: dig
Описание: Запрашивает DNS-информацию (A, MX, NS записи и т.д.). Полезно для диагностики DNS. Пример: dig google.com.
Источник: https://man7.org/linux/man-pages/man1/dig.1.html

Команда: nslookup
Описание: Запрашивает DNS-сервер для получения информации о домене. Менее гибкая, чем dig. Пример: nslookup google.com.
Источник: https://man7.org/linux/man-pages/man1/nslookup.1.html

Команда: whois
Описание: Получает информацию о владельце домена или IP-адреса из базы WHOIS. Пример: whois google.com.
Источник: https://man7.org/linux/man-pages/man1/whois.1.html

Команда: ssh
Описание: Подключается к удалённому хосту по протоколу SSH для выполнения команд или интерактивной работы. Опции: -p (порт), -i (ключ). Пример: ssh user@host.
Источник: https://man7.org/linux/man-pages/man1/ssh.1.html

Команда: scp
Описание: Копирует файлы между хостами по SSH. Опции: -r (рекурсивно), -P (порт). Пример: scp file.txt user@host:/remote/path.
Источник: https://man7.org/linux/man-pages/man1/scp.1.html

Команда: sftp
Описание: Интерактивный клиент для передачи файлов по SSH. Поддерживает команды, подобные FTP. Пример: sftp user@host.
Источник: https://man7.org/linux/man-pages/man1/sftp.1.html

Команда: rsync
Описание: Синхронизирует файлы и директории локально или между хостами с оптимизацией передачи. Опции: -a (архивный режим), -v (подробный), --delete (удалять лишние). Пример: rsync -av /src user@host:/dst.
Источник: https://man7.org/linux/man-pages/man1/rsync.1.html

Команда: ftp
Описание: Клиент для передачи файлов по протоколу FTP. Устаревший, заменяется sftp или curl. Пример: ftp ftp.example.com.
Источник: https://man7.org/linux/man-pages/man1/ftp.1.html

Команда: telnet
Описание: Подключается к удалённому хосту по протоколу Telnet. Небезопасен, используется для тестирования. Пример: telnet host 23.
Источник: https://man7.org/linux/man-pages/man1/telnet.1.html

Команда: nc
Описание: Универсальный сетевой инструмент (netcat) для чтения и записи данных через TCP/UDP. Используется для тестирования, чата, перенаправления. Пример: nc -l 12345.
Источник: https://man7.org/linux/man-pages/man1/nc.1.html

Команда: tcpdump
Описание: Захватывает и анализирует сетевые пакеты. Полезно для диагностики сети. Опции: -i (интерфейс), -w (запись в файл). Пример: tcpdump -i eth0 port 80.
Источник: https://man7.org/linux/man-pages/man8/tcpdump.8.html

Команда: wireshark
Описание: Графический анализатор сетевых пакетов. Может запускаться в терминале с tshark. Пример: wireshark -i eth0.
Источник: https://www.wireshark.org/docs/man-pages/wireshark.html

Команда: iptables
Описание: Управляет правилами межсетевого экрана для фильтрации и NAT. Устаревшая, заменяется nftables. Пример: iptables -A INPUT -p tcp --dport 22 -j ACCEPT.
Источник: https://man7.org/linux/man-pages/man8/iptables.8.html

Команда: nft
Описание: Управляет правилами межсетевого экрана с помощью nftables, современного преемника iptables. Пример: nft add rule ip filter input tcp dport 22 accept.
Источник: https://www.netfilter.org/projects/nftables/

Команда: ufw
Описание: Упрощённый интерфейс для управления межсетевым экраном (на базе iptables или nftables). Пример: ufw allow 22.
Источник: https://man7.org/linux/man-pages/man8/ufw.8.html

Команда: nmap
Описание: Сканирует сеть для обнаружения хостов, портов и сервисов. Используется для аудита безопасности. Опции: -sS (TCP SYN), -p (порты). Пример: nmap 192.168.1.0/24.
Источник: https://man7.org/linux/man-pages/man1/nmap.1.html

Команда: traceroute6
Описание: Аналог traceroute для IPv6-сетей, показывает маршрут пакетов. Пример: traceroute6 google.com.
Источник: https://man7.org/linux/man-pages/man8/traceroute6.8.html

Команда: ping6
Описание: Аналог ping для IPv6-сетей, проверяет доступность хоста. Пример: ping6 -c 4 ipv6.google.com.
Источник: https://man7.org/linux/man-pages/man8/ping.8.html

Команда: dhclient
Описание: Получает IP-адрес и сетевые настройки от DHCP-сервера. Пример: dhclient eth0.
Источник: https://man7.org/linux/man-pages/man8/dhclient.8.html

Команда: nmcli
Описание: Управляет сетевыми подключениями через NetworkManager. Поддерживает Wi-Fi, Ethernet, VPN. Пример: nmcli con up id "MyWiFi".
Источник: https://man7.org/linux/man-pages/man1/nmcli.1.html

Команда: iw
Описание: Управляет беспроводными сетевыми интерфейсами (Wi-Fi). Пример: iw dev wlan0 scan.
Источник: https://wireless.wiki.kernel.org/en/users/documentation/iw

Команда: iwconfig
Описание: Настраивает параметры беспроводных интерфейсов. Устаревшая, заменяется iw. Пример: iwconfig wlan0 essid "MyWiFi".
Источник: https://man7.org/linux/man-pages/man8/iwconfig.8.html

Команда: cron
Описание: Планировщик задач, выполняющий команды по расписанию. Управляется через crontab. Пример: crontab -e.
Источник: https://man7.org/linux/man-pages/man8/cron.8.html

Команда: crontab
Описание: Редактирует или просматривает файлы расписания задач cron для пользователя. Опции: -e (редактировать), -l (просмотреть). Пример: crontab -l.
Источник: https://man7.org/linux/man-pages/man1/crontab.1.html

Команда: at
Описание: Планирует выполнение команды в указанное время (однократно). Пример: echo "backup.sh" | at now + 1 hour.
Источник: https://man7.org/linux/man-pages/man1/at.1.html

Команда: batch
Описание: Планирует выполнение команды, когда загрузка системы низкая. Аналог at. Пример: echo "process.sh" | batch.
Источник: https://man7.org/linux/man-pages/man1/batch.1.html

Команда: nice
Описание: Задаёт приоритет выполнения команды (от -20 до 19, ниже — выше приоритет). Пример: nice -n 10 long_running_task.
Источник: https://man7.org/linux/man-pages/man1/nice.1.html

Команда: renice
Описание: Изменяет приоритет уже запущенного процесса. Пример: renice 5 -p 1234.
Источник: https://man7.org/linux/man-pages/man8/renice.8.html

Команда: nohup
Описание: Запускает команду, игнорируя сигнал завершения при выходе из терминала. Вывод направляется в nohup.out. Пример: nohup long_running.sh &.
Источник: https://man7.org/linux/man-pages/man1/nohup.1.html

Команда: screen
Описание: Создаёт виртуальные терминалы, которые сохраняются после отключения. Полезно для долгих процессов. Пример: screen -S mysession.
Источник: https://man7.org/linux/man-pages/man1/screen.1.html

Команда: tmux
Описание: Современная альтернатива screen, поддерживает разделение окон и более гибкую настройку. Пример: tmux new -s mysession.
Источник: https://man7.org/linux/man-pages/man1/tmux.1.html

Команда: watch
Описание: Периодически выполняет команду и показывает её вывод. Опция -n задаёт интервал. Пример: watch -n 1 df -h.
Источник: https://man7.org/linux/man-pages/man1/watch.1.html

Команда: env
Описание: Выводит или изменяет переменные окружения для команды. Пример: env PATH=/new/path program.
Источник: https://man7.org/linux/man-pages/man1/env.1.html

Команда: export
Описание: Экспортирует переменные окружения в дочерние процессы. Пример: export MYVAR=value.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Environment

Команда: unset
Описание: Удаляет переменную окружения или функцию. Пример: unset MYVAR.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Unsetting

Команда: alias
Описание: Создаёт псевдоним для команды или набора команд. Пример: alias ll='ls -l'.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Aliases

Команда: unalias
Описание: Удаляет псевдоним. Пример: unalias ll.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Aliases

Команда: history
Описание: Показывает историю ранее введённых команд в оболочке. Пример: history | grep ssh.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Bash-History-Builtins

Команда: jobs
Описание: Показывает список фоновых задач в текущей сессии оболочки. Пример: jobs.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Job-Control-Builtins

Команда: fg
Описание: Выводит фоновую задачу на передний план. Пример: fg %1.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Job-Control-Builtins

Команда: bg
Описание: Переводит приостановленную задачу в фоновый режим. Пример: bg %1.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Job-Control-Builtins

Команда: disown
Описание: Отсоединяет задачу от текущей сессии оболочки, чтобы она продолжила работу после выхода. Пример: disown %1.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Job-Control-Builtins

Команда: wait
Описание: Ожидает завершения фоновой задачи. Пример: wait %1.
Источник: https://www.gnu.org/software/bash/manual/bash.html#Job-Control-Builtins

Команда: clear
Описание: Очищает экран терминала. Пример: clear.
Источник: https://man7.org/linux/man-pages/man1/clear.1.html

Команда: reset
Описание: Сбрасывает состояние терминала, исправляя ошибки отображения. Пример: reset.
Источник: https://man7.org/linux/man-pages/man1/reset.1.html

Команда: tput
Описание: Управляет атрибутами терминала (цвета, курсор, очистка). Пример: tput setaf 2 (установить зелёный цвет).
Источник: https://man7.org/linux/man-pages/man1/tput.1.html

Команда: stty
Описание: Настраивает параметры терминала (например, эхо ввода, размер). Пример: stty -echo.
Источник: https://man7.org/linux/man-pages/man1/stty.1.html

Команда: tty
Описание: Показывает имя текущего терминала. Пример: tty.
Источник: https://man7.org/linux/man-pages/man1/tty.1.html

Команда: basename
Описание: Извлекает имя файла из пути, удаляя директории. Опция -s удаляет суффикс. Пример: basename /path/to/file.txt.
Источник: https://man7.org/linux/man-pages/man1/basename.1.html

Команда: dirname
Описание: Извлекает путь к директории из полного пути, удаляя имя файла. Пример: dirname /path/to/file.txt.
Источник: https://man7.org/linux/man-pages/man1/dirname.1.html

Команда: readlink
Описание: Показывает, куда указывает символическая ссылка. Опция -f возвращает канонический путь. Пример: readlink -f symlink.
Источник: https://man7.org/linux/man-pages/man1/readlink.1.html

Команда: realpath
Описание: Возвращает абсолютный канонический путь к файлу, разрешая все ссылки. Пример: realpath file.txt.
Источник: https://man7.org/linux/man-pages/man1/realpath.1.html

Команда: mktemp
Описание: Создаёт временный файл или директорию с уникальным именем. Опции: -d (директория). Пример: mktemp /tmp/tempfile.XXXXXX.
Источник: https://man7.org/linux/man-pages/man1/mktemp.1.html

Команда: shred
Описание: Безопасно удаляет файлы, перезаписывая их содержимое случайными данными. Опции: -u (удалить после), -n (число проходов). Пример: shred -u file.txt.
Источник: https://man7.org/linux/man-pages/man1/shred.1.html

Команда: wipe
Описание: Безопасно стирает данные с диска, аналог shred, но с другими алгоритмами. Пример: wipe file.txt.
Источник: https://wipe.sourceforge.net/

Команда: fallocate
Описание: Резервирует место на диске для файла без записи данных. Полезно для больших файлов. Пример: fallocate -l 1G bigfile.
Источник: https://man7.org/linux/man-pages/man1/fallocate.1.html

Команда: truncate
Описание: Изменяет размер файла, увеличивая или уменьшая его. Опция -s задаёт размер. Пример: truncate -s 10M file.txt.
Источник: https://man7.org/linux/man-pages/man1/truncate.1.html

Команда: split
Описание: Разделяет файл на части фиксированного размера или по строкам. Опции: -b (по байтам), -l (по строкам). Пример: split -b 1M bigfile.
Источник: https://man7.org/linux/man-pages/man1/split.1.html

Команда: csplit
Описание: Разделяет файл на части по шаблону или количеству строк. Более гибкий, чем split. Пример: csplit file.txt '/^#/' '{*}'.
Источник: https://man7.org/linux/man-pages/man1/csplit.1.html

Команда: nl
Описание: Нумерует строки в файле. Опции: -b (тип нумерации), -n (формат). Пример: nl -b a file.txt.
Источник: https://man7.org/linux/man-pages/man1/nl.1.html

Команда: pr
Описание: Форматирует файл для печати, добавляя заголовки, колонки и т.д. Пример: pr -h "Report" file.txt.
Источник: https://man7.org/linux/man-pages/man1/pr.1.html

Команда: fold
Описание: Разбивает длинные строки на заданную ширину. Опция -w задаёт ширину. Пример: fold -w 80 file.txt.
Источник: https://man7.org/linux/man-pages/man1/fold.1.html

Команда: expand
Описание: Преобразует табуляцию в пробелы. Опция -t задаёт ширину табуляции. Пример: expand -t 4 file.txt.
Источник: https://man7.org/linux/man-pages/man1/expand.1.html

Команда: unexpand
Описание: Преобразует пробелы в табуляцию для экономии места. Пример: unexpand -t 4 file.txt.
Источник: https://man7.org/linux/man-pages/man1/unexpand.1.html

Команда: od
Описание: Выводит содержимое файла в различных форматах (восьмеричный, шестнадцатеричный и т.д.). Пример: od -tx4 file.bin.
Источник: https://man7.org/linux/man-pages/man1/od.1.html

Команда: hexdump
Описание: Показывает содержимое файла в шестнадцатеричном и ASCII-формате. Пример: hexdump -C file.bin.
Источник: https://man7.org/linux/man-pages/man1/hexdump.1.html

Команда: xxd
Описание: Создаёт шестнадцатеричный дамп файла или преобразует его обратно. Пример: xxd file.bin.
Источник: https://man7.org/linux/man-pages/man1/xxd.1.html

Команда: strings
Описание: Извлекает читаемые строки из бинарного файла. Полезно для анализа исполняемых файлов. Пример: strings /bin/ls.
Источник: https://man7.org/linux/man-pages/man1/strings.1.html

Команда: base64
Описание: Кодирует или декодирует данные в формате Base64. Опция -d для декодирования. Пример: echo "text" | base64.
Источник: https://man7.org/linux/man-pages/man1/base64.1.html

Команда: md5sum
Описание: Вычисляет или проверяет MD5-хеш файла. Пример: md5sum file.txt.
Источник: https://man7.org/linux/man-pages/man1/md5sum.1.html

Команда: sha1sum
Описание: Вычисляет или проверяет SHA-1 хеш файла. Пример: sha1sum file.txt.
Источник: https://man7.org/linux/man-pages/man1/sha1sum.1.html

Команда: sha256sum
Описание: Вычисляет или проверяет SHA-256 хеш файла. Более безопасный, чем MD5. Пример: sha256sum file.txt.
Источник: https://man7.org/linux/man-pages/man1/sha256sum.1.html

Команда: sha512sum
Описание: Вычисляет или проверяет SHA-512 хеш файла. Пример: sha512sum file.txt.
Источник: https://man7.org/linux/man-pages/man1/sha512sum.1.html

Команда: cksum
Описание: Вычисляет CRC32 контрольную сумму файла. Пример: cksum file.txt.
Источник: https://man7.org/linux/man-pages/man1/cksum.1.html

Команда: sum
Описание: Вычисляет простую контрольную сумму файла (устаревшая). Пример: sum file.txt.
Источник: https://man7.org/linux/man-pages/man1/sum.1.html

Команда: gpg
Описание: Шифрует, расшифровывает и подписывает файлы с использованием GnuPG. Опции: -c (симметричное шифрование), -e (шифровать). Пример: gpg -c file.txt.
Источник: https://man7.org/linux/man-pages/man1/gpg.1.html

Команда: openssl
Описание: Многофункциональный инструмент для работы с SSL/TLS, шифрованием, сертификатами и хешами. Пример: openssl enc -aes-256-cbc -in file.txt -out file.enc.
Источник: https://man7.org/linux/man-pages/man1/openssl.1.html

Команда: passwd
Описание: Изменяет пароль пользователя. Без аргументов меняет пароль текущего пользователя. Пример: passwd user.
Источник: https://man7.org/linux/man-pages/man1/passwd.1.html

Команда: chpasswd
Описание: Обновляет пароли пользователей из файла или ввода. Используется для массового изменения. Пример: echo "user:pass" | chpasswd.
Источник: https://man7.org/linux/man-pages/man8/chpasswd.8.html

Команда: adduser
Описание: Интерактивно создаёт нового пользователя с настройкой пароля, домашней директории и т.д. Пример: adduser newuser.
Источник: https://man7.org/linux/man-pages/man8/adduser.8.html

Команда: deluser
Описание: Удаляет пользователя, аналог userdel. Опция --remove-home удаляет домашнюю директорию. Пример: deluser --remove-home user.
Источник: https://man7.org/linux/man-pages/man8/deluser.8.html

Команда: visudo
Описание: Безопасно редактирует файл /etc/sudoers для настройки привилегий sudo. Пример: visudo.
Источник: https://man7.org/linux/man-pages/man8/visudo.8.html

Команда: logrotate
Описание: Управляет ротацией логов (сжатие, удаление старых). Настраивается через /etc/logrotate.conf. Пример: logrotate -f /etc/logrotate.conf.
Источник: https://man7.org/linux/man-pages/man8/logrotate.8.html

Команда: anacron
Описание: Выполняет периодические задачи, пропущенные из-за выключенной системы. Пример: anacron -f.
Источник: https://man7.org/linux/man-pages/man8/anacron.8.html

Команда: lscpu
Описание: Показывает информацию о процессорах: количество ядер, частота, архитектура. Пример: lscpu.
Источник: https://man7.org/linux/man-pages/man1/lscpu.1.html

Команда: lsblk
Описание: Показывает список блочных устройств (диски, разделы) и их точки монтирования. Пример: lsblk.
Источник: https://man7.org/linux/man-pages/man8/lsblk.8.html

Команда: lshw
Описание: Показывает подробную информацию об оборудовании системы (CPU, память, диски и т.д.). Пример: lshw -short.
Источник: https://man7.org/linux/man-pages/man1/lshw.1.html

Команда: lspci
Описание: Показывает список PCI-устройств (видеокарты, сетевые карты и т.д.). Пример: lspci.
Источник: https://man7.org/linux/man-pages/man8/lspci.8.html

Команда: lsusb
Описание: Показывает список подключённых USB-устройств. Пример: lsusb.
Источник: https://man7.org/linux/man-pages/man8/lsusb.8.html

Команда: dmidecode
Описание: Извлекает информацию об оборудовании из DMI/SMBIOS (производитель, модель и т.д.). Пример: dmidecode -t memory.
Источник: https://man7.org/linux/man-pages/man8/dmidecode.8.html

Команда: hdparm
Описание: Настраивает и отображает параметры жёстких дисков (SATA/IDE). Пример: hdparm -i /dev/sda.
Источник: https://man7.org/linux/man-pages/man8/hdparm.8.html

Команда: smartctl
Описание: Проверяет состояние и SMART-данные жёстких дисков. Пример: smartctl -a /dev/sda.
Источник: https://man7.org/linux/man-pages/man8/smartctl.8.html

Команда: badblocks
Описание: Проверяет диск на наличие повреждённых блоков. Пример: badblocks -v /dev/sdb.
Источник: https://man7.org/linux/man-pages/man8/badblocks.8.html

Команда: tune2fs
Описание: Настраивает параметры файловой системы ext2/ext3/ext4 (например, интервалы проверки). Пример: tune2fs -c 30 /dev/sda1.
Источник: https://man7.org/linux/man-pages/man8/tune2fs.8.html

Команда: e2fsck
Описание: Проверяет и исправляет файловую систему ext2/ext3/ext4. Пример: e2fsck -f /dev/sda1.
Источник: https://man7.org/linux/man-pages/man8/e2fsck.8.html

Команда: resize2fs
Описание: Изменяет размер файловой системы ext2/ext3/ext4. Пример: resize2fs /dev/sda1.
Источник: https://man7.org/linux/man-pages/man8/resize2fs.8.html

Команда: xfs_repair
Описание: Проверяет и исправляет файловую систему XFS. Пример: xfs_repair /dev/sda1.
